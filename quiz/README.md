# Pliki produktu: CyberQuiz

Planowana struktura (powstaje w zadaniach #4–#8):

| Plik | Zawartość | Zadanie |
|---|---|---|
| `index.html` | struktura strony: ekran startowy, ekran pytania, ekran wyniku, stopka z wersją | #5 |
| `styl.css` | wygląd i czytelność (komputer i telefon) | #8 |
| `pytania.js` | tablica 10 pytań (format: [D-006](../docs/04-dziennik-decyzji.md#d-006--pytania-w-pliku-pytaniajs-nie-w-json)) | #4, #9–#11 |
| `quiz.js` | logika: wyświetlanie pytań, zatwierdzanie, wynik, ponowna gra | #6, #7 |

Szczegółowy opis formatu pytania dopisze tutaj właściciel zadania #4.
